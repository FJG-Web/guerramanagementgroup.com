# Security Policy

We take the security of Guerra Management Group Corp. seriously and welcome
responsible disclosure.

## Reporting a Vulnerability

- **Email:** security@guerramanagementgroup.com
- **Machine-readable policy:** <https://www.guerramanagementgroup.com/.well-known/security.txt>

Please include steps to reproduce, affected URL(s), and any proof-of-concept.
We aim to **acknowledge reports within 1 business day** and will keep you
updated on remediation progress.

Please do **not**:

- Open a public GitHub issue for a security report.
- Run automated scanning or load testing that degrades service for other users.

## Scope

- `https://www.guerramanagementgroup.com` (this repository)
- The contact API at `guerra-contact-api.vercel.app`

## Out of Scope

- Findings requiring physical access or social engineering of staff
- Volumetric / denial-of-service testing
- Reports affecting only outdated or unsupported browsers
